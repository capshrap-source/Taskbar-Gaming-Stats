# 🏴‍☠️ Taskbar Gaming Stats v1.0.0

**The first official release is here!**

Taskbar Gaming Stats is a lightweight Windows 11 performance monitoring application built for gamers and PC enthusiasts.

### What's included

- Real-time taskbar hardware monitoring.
- CPU, GPU and RAM statistics.
- GPU temperature and clock speeds.
- Native DXGI-based FPS estimates.
- Estimated 1% lows and frametime.
- Customisable in-game overlay.
- Top three CPU, GPU and RAM consuming processes.
- Live network monitoring.
- TGS resource self-monitoring.
- Quick keyboard shortcuts.
- Professional Windows installer.
- Optional Windows startup.

### Installation

Download **TaskbarGamingStats-Setup-1.0.0.exe** from the release assets below and follow the installation wizard.

### Release Status

- Application tested.

### Known Limitations

FPS readings are estimates based on desktop frame updates. Exclusive fullscreen support and hardware sensor availability may vary. The installer is currently unsigned.
